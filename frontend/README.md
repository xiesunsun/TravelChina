## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Ensure backend API is running at `http://localhost:8000` (or set `VITE_API_BASE_URL`)
3. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key (optional for fallback mode)
4. Run the app:
   `npm run dev`
5. Use the login page to register/login before accessing records
